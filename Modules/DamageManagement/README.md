# Damage Management Module

**Version:** 1.0.0  
**Author:** Hackermiind  
**Module Name:** DamageManagement  

## Description

Comprehensive Damage Management Module - Track damaged products, manage dispatches to suppliers, and handle compensation claims with full documentation and reporting.

**This is a complete free module for non commercial use.**

## Features

- Track damaged products with detailed information
- Manage dispatches to suppliers with full documentation
- Handle compensation claims with accurate calculations
- Monitor stock adjustments and inventory impact
- Generate comprehensive reports and analytics
- Modern dashboard with visual statistics
- Stock impact tracking with history
- Approval workflow for damage records
- Partial dispatch support
- Complete audit trail

## Installation

1. Place the module in `Modules/DamageManagement/`
2. Run the installation from the module management page
3. Configure permissions for your users
4. Start tracking damage records

## Requirements

- PHP 7.4 or higher
- Laravel 8.x or higher
- MySQL 5.7 or higher

## Usage

### Creating Damage Records

Navigate to **Damage Management > All Damage Records** and click **Add Damage Record**.

### Key Features

1. **Record Creation**
   - Select product/variation
   - Enter quantity
   - Set compensation basis
   - Add notes and attachments

2. **Dispatch Management**
   - Track dispatch status
   - Partial dispatch support
   - Automatic stock adjustment

3. **Approval Workflow**
   - Pending/Approved/Rejected status
   - Automatic stock deduction on approval
   - Full audit trail

4. **Reports & Analytics**
   - Dashboard with statistics
   - Stock impact reports
   - Financial summaries
   - Product performance tracking

## Permissions

- `damage_record.view` - View damage records
- `damage_record.create` - Create damage records
- `damage_record.update` - Update damage records
- `damage_record.delete` - Delete damage records
- `damage_dispatch.view` - View dispatches
- `damage_dispatch.create` - Create dispatches
- `damage_dispatch.delete` - Delete dispatches
